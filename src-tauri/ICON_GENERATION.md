# Generador de icono para pdf-tool

Este archivo contiene la configuración para generar un nuevo icono para la aplicación pdf-tool.

## Requisitos

- Imagen en formato PNG (256x256 px o mayor)
- El icono debe tener fondo transparente si es posible
- Se recomienda usar colores que representen PDF y herramientas

## Proceso de creación

1. Crear una imagen PNG con el logo deseado para pdf-tool
2. Convertir a formato .ico con múltiples tamaños (16x16, 32x32, 48x48, 256x256)
3. Reemplazar el icono existente en src-tauri/icons/icon.ico

## Iconos recomendados

- Colores: Azul y verde (representan confianza y tecnología)
- Forma: Representación de documento PDF o herramientas
- Estilo: Moderno y minimalista
